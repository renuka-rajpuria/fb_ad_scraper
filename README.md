# FB Ad Scraper

A tool for scraping and analyzing Facebook ads data.

## Overview

This project automates the collection of Facebook ad data for research and analysis purposes.

## Setup

```bash
# Clone the repository
git clone git@github.com:renuka-rajpuria/fb_ad_scraper.git
cd fb_ad_scraper

# Install dependencies
pip install -r requirements.txt
```
